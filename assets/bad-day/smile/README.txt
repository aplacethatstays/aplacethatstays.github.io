Put your FUNNY photos and videos here for "Make me smile".

Supported formats: .jpg .jpeg .png .webp .mp4 .webm

Then open src/config.ts, find badDayMedia.smile, and add an entry like:

  { kind: 'image', src: 'goofy.jpg', caption: 'the day she tried to cook' }
  { kind: 'video', src: 'laughing.mp4', caption: 'that voice note, but video' }

Only write the filename — the folder path is added for you.
